# Prompt 277

## Resources

aws_s3_bucket, aws_s3_bucket_object

## Prompt

Create S3 bucket with bucket name = "mybucket". Then create a bucket object resource for a file at source location "path/to/file" and upload the object to the bucket.

## Difficulty

2

## Intent

Has an aws_s3_bucket resource

Has an aws_s3_object resource
with bucket = bucket id OR name
with source = "path/to/file"
