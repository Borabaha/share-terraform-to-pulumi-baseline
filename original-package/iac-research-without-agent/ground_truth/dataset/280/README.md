# Prompt 280

## Resources

aws_s3_bucket, aws_s3_bucket_ownership_controls

## Prompt

Create a S3 bucket with bucket name = "mybucket". And create a bucket ownership controls resource to set object ownership to bucket owner preferred.

## Difficulty

2

## Intent

Has an aws_s3_bucket resource

Has an aws_s3_bucket_ownership_controls
with bucket = bucket id OR name
and rule with object_ownership = "BucketOwnerPreferred"
