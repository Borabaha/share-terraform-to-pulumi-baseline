# Prompt 410

## Resources

aws_db_instance

## Prompt

Create an AWS mySQL instance. Any changes on it will be applied immediately

## Difficulty

2

## Intent

Has one "aws_db_instance" resource
with one "allocated_storage"
with one "engine" with value "mysql"
with one "instance_class" 
with one "password"
with one "username"
with one "apply_immediately" set to true
