# Prompt 218

## Resources

aws_rds_cluster, aws_vpc

## Prompt

Create an mySQL cluster with 100 GB allocated to us-east-1a, us-east-1b, us-east-1c.

## Difficulty

3

## Intent

Has one "aws_rds_cluster" resource
with one "allocated_storage" = 100
with one "availability_zones" = ["us-east-1a", "us-east-1b", "us-east-1c"]
with one "engine" = "mysql"
