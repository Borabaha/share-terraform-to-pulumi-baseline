# Prompt 278

## Resources

aws_s3_bucket, aws_s3_object

## Prompt

I have a PDF with path "assets/test.pdf". Make an AWS resource to store this PDF and upload it.

## Difficulty

2

## Intent

Has an aws_s3_bucket resource

Has an aws_s3_object resource
with bucket = bucket id OR name
with source = "assets/test.pdf"
