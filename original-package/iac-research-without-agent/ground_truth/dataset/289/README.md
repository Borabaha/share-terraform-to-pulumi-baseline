# Prompt 289

## Resources

aws_s3_bucket, aws_s3_bucket_request_payment_configuration

## Prompt

Create a S3 bucket where the bucket owner pays for fees.

## Difficulty

2

## Intent

Has an aws_s3_bucket

Has an aws_s3_bucket_request_payment_configuration
with bucket = bucket id OR name
with payer = "BucketOwner"
